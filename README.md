# 🧠 Quiz Game Website

## 📄 Description

- An interactive quiz game based on Islamic history where users can test their knowledge through a series of questions. At the end of the quiz, users receive their final score along with a personalized compliment based on their performance, making the experience both educational and engaging.

---

## ⚙️ Technologies Used

- Html
- Tailwind CSS, DaisyUI
- JavaScript (ES6+)

---

## ✨ 3 Features About My Project

- ❓ Interactive Questions – Answer multiple-choice questions based on Islamic history.
- 📊 Result Evaluation – Get a final score at the end of the quiz.
- 🎉 Personalized Feedback – Receive a compliment message based on your performance.
